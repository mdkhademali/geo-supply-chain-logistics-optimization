## Geospatial Supply Chain & Logistics Optimization

## Overview
This project implements a geospatial logistics optimization system using Python, GIS, and network analysis.

## Features
- Road Network Extraction (OSMnx)
- Vehicle Routing Problem (VRP)
- Shortest Path Optimization
- Travel Time Prediction (ML)
- Interactive Map Visualization

## Technologies
- Python
- GeoPandas
- NetworkX
- OSMnx
- Folium 

## Output
- Optimized route
- Interactive map

## Future Work
- Multi-vehicle VRP (OR-Tools)
- Real-time traffic integration
- Streamlit dashboard
