## Overview  
This project implements a **Geospatial Logistics Optimization System** using Python, GIS, and network analysis techniques. It integrates spatial data, routing algorithms, and machine learning to optimize supply chain operations.

---

## Features  
- Road Network Extraction (OSMnx)  
- Vehicle Routing Problem (VRP)  
- Shortest Path Optimization  
- Travel Time Prediction (ML)  
- Interactive Map Visualization  

---

## Technologies  
- Python  
- GeoPandas  
- NetworkX  
- OSMnx  
- Folium
